# Verify ImageJ-rs

This skill drives `ImageJ-rs` (`ij-cli` and the workspace test suite) alongside the unmodified `original_imagej` 1.54u Java oracle.

## Launch

`ImageJ-rs` is a short-lived CLI and library workspace paired with a batch-mode Java oracle (`tools/oracle/ij-oracle.jar`). Build both once from the repository root (`/Users/nauti/GitHub/ImageJ-rs`):

```bash
./tools/oracle/build_oracle.sh
cargo build --workspace
```

Ready means `tools/oracle/ij-oracle.jar` exists and `cargo build --workspace` exits with code `0`.

## Doctor

Run the read-only health check before driving any feature:

```bash
cargo run --quiet --bin ij-cli -- doctor
```

Expected output:
```text
IJ_ORACLE_VERSION=1.54u
IJ_RS_DOCTOR=OK
```

If `IJ_ORACLE_VERSION=1.54u` or `IJ_RS_DOCTOR=OK` is missing, rebuild the oracle with `./tools/oracle/build_oracle.sh`.

## Drive

Run the full verification lever or drive individual journeys in isolated output directories:

```bash
# Full verification gate (ledger sync + doctor + unit/parity tests + Vertical Slice 1 proof)
./tools/verify.sh

# Drive Vertical Slice 1 directly into an isolated evidence directory
cargo run --quiet --bin ij-cli -- slice1 --out-dir /Users/nauti/GitHub/ImageJ-rs/verification/evidence/manual_run

# Drive differential parity check between Rust Session and Java 1.54u Oracle
cargo run --quiet --bin ij-cli -- parity-check
```

## Evidence

Every verification run writes proof artifacts to `/Users/nauti/GitHub/ImageJ-rs/verification/evidence/latest/` (or the directory passed to `--out-dir`):

- `Results.tsv`: Tab-separated measurement table generated by Rust `Session::dispatch(Command::Measure)`.
- `ramp_saved.tif`: 8-bit uncompressed TIFF written by `ij-io::save_tiff`.
- `recorded_macro.ijm`: Macro transcript recorded by `Session.macro_recorder`.
- `slice1_stdout.txt` and `parity_stdout.txt`: Captured CLI transcripts proving `PARITY_OK`.

Proof standards:
- Exercise `Session::dispatch` and `ij-cli` user entry points, never internal struct setters.
- Verify both stdout transcripts and written files (`Results.tsv`, `ramp_saved.tif`, `recorded_macro.ijm`).
- Compare Rust outputs directly against `./tools/oracle/run_oracle.sh` (the real ImageJ 1.54u runtime), never against hand-typed mock numbers alone.

## Cleanup

`ij-cli` and `run_oracle.sh -batch` exit immediately after completing each run. Temporary bridge TIFFs under `$TMPDIR/ij_bridge_<pid>` are removed automatically by `JavaOracleBridge::run_macro_on_image`. Do not delete `/Users/nauti/GitHub/ImageJ-rs/verification/evidence/latest/`; proof artifacts must survive cleanup.

## Helpers

- `./tools/verify.sh` — Single-command verification gate for agents and CI.
- `./tools/oracle/run_oracle.sh -eval "<macro>" -batch` — Runs an ImageJ 1.54u macro in headless `UIElement` mode.
- `python3 tools/ledger/sync_ledger.py --check` — Verifies that `docs/command_ledger.md` and `crates/ij-session/src/generated_commands.rs` match `original_imagej/`.
